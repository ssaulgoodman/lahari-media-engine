Veo 3.1

Scenes are independent — can work on multiple scenes in parallel.
Shots within a scene are sequential — shot N+1 needs shot N locked.

Scene 1 Shot 1 ← style + char refs + env ref (no continuity ref) Start frame → End frame → Lock | end frame passes down ↓ Shot 2 ← style + char refs + env ref + Shot 1 end frame Start frame → End frame → Lock | end frame passes down ↓ Shot 3 ← ... (continues sequentially) Scene 2 (independent, can run in parallel) Shot 1 ← style + char refs + env ref (no continuity ref) ...

Shot Start Frame — Reference Index

Image 1 = Character reference: Kolasura ← cast_members.reference_asset_id Image 2 = Character reference: Mahalakshmi ← cast_members.reference_asset_id Image 3 = Style reference ← projects.style_asset_id Image 4 = Environment reference: Vaikuntha ← environments.reference_asset_id Image 5 = Continuity reference ← prev shot's end_image_asset_id REFERENCE USAGE Character refs → preserve identity, face, hairstyle, costume, proportions Style ref → transfer lighting, palette, texture, lens language Environment ref → transfer location design, materials, weather, ambience Continuity ref → continue action, framing, emotional beat, object continuity PRIORITY ORDER 1. Character identity 2. Temporal continuity 3. Environment fidelity 4. Style fidelity NEGATIVE CONSTRAINTS Do not borrow identity from style ref Do not redesign the character Do not change setting unless scene requires it Do not break continuity in costume, pose, or props No text, no watermark, no logos

Complete AI Call Chain

1
analyzeAudio (×3 parallel)
Gemini 3 Pro
In: audio file → Out: lyrics + structure + meaning
Stored: projects.lyrics, musical_structure, meaning
2
generateConcepts
Gemini 3 Pro
In: lyrics + meaning + structure → Out: 3 concept options
Stored: projects.concept_options → user locks → projects.locked_concept
3
planScenes
Claude Sonnet (tool_use)
In: concept + lyrics + structure + meaning → Out: cast[] + environments[] + scenes[shots[]]
Stored: cast_members, environments, scenes, shots (direction placeholders only)

brainstormStyleDirections
Claude Sonnet
In: concept + lyrics + meaning + script summary → Out: 4 style directions (text)
Not persisted (client state)
5
generateSingleStyleImage (×N user selects)
Imagen 4
In: style direction text + subject → Out: style image
Stored: assets (category: style)
6
enrichStyleDNA
Claude Sonnet (vision)
In: locked style image + short desc → Out: enriched style DNA paragraph
Stored: projects.style_description, style_asset_id
7
generateCharacterLooks (×N characters, 3 each)
Gemini 3 Pro Image Preview
In: char desc + style DNA + style image ref → Out: 3 look images
Stored: assets (category: character) → user locks → cast_members.reference_asset_id
8
generateEnvironmentLooks (×N environments, 3 each)
Gemini 3 Pro Image Preview
In: env desc + style DNA + style image ref → Out: 3 look images
Stored: assets (category: environment) → user locks → environments.reference_asset_id
9
writeShotPrompts (batch, all shots)
Claude Sonnet
In: script skeleton + style DNA + char descs + concept + lyrics → Out: visualPrompt + motionPrompt per shot
Stored: shots.visual_prompt, shots.motion_prompt
10
generateShotStartFrame (×N shots, sequential per scene)
Gemini 3 Pro Image Preview
In: visualPrompt + char refs + style ref + env ref + prev end frame → Out: start frame image
Stored: assets (shot_image) + shots.image_asset_id
11
generateShotEndFrame (×N shots)
Gemini 3 Pro Image Preview
In: start frame + style ref + motionPrompt → Out: end frame image
Stored: assets (shot_end_frame) + shots.end_image_asset_id
12
generateVideo (×N shots)
Veo 3.1
In: start keyframe + end keyframe + motion prompt + scene context → Out: video clip (MP4)
Stored: assets (shot_video) + shots.video_asset_id

Data Flow

Audio File ↓ [Gemini × 3] → lyrics, meaning, structure → projects table ↓ [Gemini] → 3 concept options → user picks → locked concept → projects.locked_concept ↓ [Claude] → cast + environments + scenes + shots → 4 tables ↓ [Claude] → 4 style text directions → client state ↓ [Imagen 4] → style images → user locks → [Claude vision] → style DNA → projects.style_* ↓ [Gemini Pro Image] ×3 per character → user locks → cast_members.reference_asset_id [Gemini Pro Image] ×3 per environment → user locks → environments.reference_asset_id ↓ [Claude] → visualPrompt + motionPrompt per shot → shots.visual_prompt, motion_prompt ↓ [Gemini Pro Image] → start frame → shots.image_asset_id [Gemini Pro Image] → end frame → shots.end_image_asset_id user locks → shots.locked = 1 → next shot receives end frame as continuity ref ↓ [Veo 3.1] → video clip → shots.video_asset_id ↓ [FFmpeg WASM] → final rendered video → client download
