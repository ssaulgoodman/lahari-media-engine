## Pacing / Duration

### 6. ~~Tell Claude the minimum shot duration~~ DONE

**Fix applied:** Both prompts now receive `minShotDuration` from the project's video model via `getModelMinDuration()`. Prompt informs Claude of the model's floor — Claude writes shots per normal pacing math, Segmind handles rounding up at generation time (fix 8).
**Commits:** `2dbcda7`, `28d65d1`

### 7. ~~Remove direct duration editing input~~ DONE
**Where:** `components/AnalysisEditor.tsx` — script phase shot cards
**Fix applied:** Duration shown as read-only text. Only changeable via pacing selection (regenerates script), split button (divides a shot), or model change (adjusts pacing).
**Commit:** `1ebcdca`

### 8. ~~Send model's nearest valid duration to Segmind~~ DONE
**Where:** `server/services/segmind.ts`
**Fix applied:** Duration selection changed from "nearest" to "smallest model duration >= shot duration". A 6s shot on Veo Fast (8s only) now correctly sends 8s. If shot exceeds all model durations, largest is used. Render timeline handles trimming.
**Commit:** `2dbcda7`
