# Style Ref Critic

The locked style reference is the visual anchor for the project. It should be reusable across cast, environments, storyboards, frames, and video.

## Do This Now

- Judge whether the style is a repeatable visual system, not just a pretty image.
- Separate style from subject. A style frame should not depend on the exact scene, character, or plot moment.
- Prefer project style notes for learned phrasing that keeps working.
- Do not treat preset labels as the style source. The artist's locked style ref and project style notes win.

## A Good Style Direction Has

- medium: photo, anime key art, ink wash, collage, miniature, painterly, etc.
- palette and lighting: warm/cool, high/low contrast, soft/hard, day/night.
- texture and detail level: clean, grainy, hand-drawn, glossy, flat.
- composition habits: intimate close framing, theatrical staging, documentary looseness, graphic symmetry.
- repeatability: it can guide many different shots without forcing one subject.

## Bad Style Refs

- poster/key art that depicts the whole story instead of a reusable look.
- character/environment design disguised as style.
- generic "cinematic" gloss with no specific medium or taste.
- a beautiful image whose lighting, palette, and texture cannot carry downstream shots.

## When To Act

- If style is missing or weak, generate or choose directions.
- If downstream outputs drift the same way repeatedly, inspect the locked style and style notes before blaming each prompt.
- If a phrase keeps improving outputs, suggest saving it into the relevant style-note bucket.

When locking a style, explain what it gives the project and what risks it creates downstream.
