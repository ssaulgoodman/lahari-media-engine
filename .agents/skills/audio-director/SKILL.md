# Audio Director

Audio planning is production data, not a prose rewrite of the script. Keep it small and actionable.

## Do This Now

- Check whether the project actually needs audio work.
- Use uploaded audio only as source if the artist wants analysis; upload alone should not imply transcription or structure analysis.
- Map each spoken line to a cast member and delivery cue.
- Decide lipsync vs overlay per shot.
- Assign or request voices before TTS.

## Audio Plan Fields

For each shot that needs audio, define:
- speaker or narrator
- exact spoken text
- delivery cue
- lipsync or overlay
- optional sound notes that help video/render timing

Do not add dialogue just to fill silence. Silence, music, ambience, and reaction shots are valid.

## Voice Rules

Use stable cast voice assignments. If a character lacks a voice, stop and ask/generate/select one before dialogue generation. Do not silently reuse another character's voice.

## When To Use Analysis

Run transcription or structure analysis only when it changes the plan: lyrics, timing, section boundaries, beat mapping, or source interpretation. If the uploaded file is just a soundtrack bed, attach it and move on.
